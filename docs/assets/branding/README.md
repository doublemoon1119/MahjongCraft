# Branding assets

- `logo.png`: the project logo, also used as the Minecraft mod icon.
- `title.png`: the "MahjongCraft" title with a transparent background, for placing over screenshots.
- `title-table.png`: the same title on the mahjong table surface, at a 2:1 ratio.
- `title.bbmodel`: the [Blockbench](https://www.blockbench.net/) model that both title images are
  rendered from. Open it in Blockbench to change the layout or render the images again.
- `banner.jpg`: a 1280×640 in-game screenshot with the title, used as the GitHub social preview
  and the mod page banner. The showcase run of the
  [debug module](../../../platform/minecraft/mod-debug/README.md) takes it.

The title is spelled with flat mahjong tiles, one tile per pixel of the letters. "Mahjong" shows the
tile faces and "Craft" shows the tile backs. The tile and table textures come from the Minecraft
mod's resources.

The letter shapes come from the 8 px proportional glyphs of
[Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font), licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/).
